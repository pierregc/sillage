#   <library> <function> <state>
#
#   cuda                  its entry point, `__global__ void <function>(`, is in cuda/src and
#                         runs on the CPU target too
#   cuda gpu-only         it is in cuda/src, but uses block barriers or warp functions: it
#                         runs only on a GPU, first in #283
#   cuda in <kernels>     a fragment function: CUDA has no rasteriser, so the kernels named,
#                         which are the vertex functions' entry points, call its shared
#                         per-pixel function for each pixel of a point
#   pending #<issue>      that issue writes it
#   metal-only: <reason>  the CUDA engine will not have it
